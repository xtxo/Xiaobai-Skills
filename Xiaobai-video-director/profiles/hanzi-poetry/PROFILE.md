# Hanzi Poetry Profile

## 目标

把中文歌词、诗句、成语或哲思文案做成“汉字本身参与表演”的竖屏短片。重点不是堆砌古风素材，而是让字形、偏旁、位置、节奏和留白直接解释含义。

## 核心视觉语法

每个重点汉字遵循：**整字出现 → 部件拆开 → 部件发生有含义的动作 → 寓意落定 → 必要时重新合字**。

示例：

- 静 → 青 + 争 → “争”抖动、“青”稳定 → 重新合成“静”。
- 稳 → 禾 + 急 → “急”震动、“禾”扎根 → 重新合成“稳”。
- 忙 → 忄 + 亡 → 忄离开，只剩“亡” → 再回到“忙”。
- 愁 → 秋 + 心 → 秋从上方落到心上 → 融合成“愁”。

## 导演原则

1. 汉字是主角，不是字幕装饰。
2. 一句最多一个主视觉机制，避免同时堆太多对象。
3. 拆字必须服务含义，不为拆而拆；并非结构拆字的歌词，用接近、平衡、漂散、交替等关系表达。
4. 字体优先楷体、宋体或可信的中文书法字体；不得使用视频生成模型直接生成核心汉字。
5. 画面保持东方留白，低饱和纸色、墨色、朱砂、苔青、旧金为主。
6. 动作有触发、中间过程、稳定结果，不允许只做淡入淡出。
7. 重要结论句主动减少背景物体，让观众只看一个字或一组关系。
8. 默认输出 1080×1920、30fps；横版仅在用户明确要求时使用。
9. 音频可来自外部歌曲。已有歌词时间戳时以歌曲为时间主轴；没有时先用视觉节奏时间轴制作样片。
10. 字幕与核心汉字分离：核心汉字位于视觉中心，歌词字幕位于底部安全区。

## 推荐镜头类型

- `split-horizontal`: 左右拆分，如 静→青/争、稳→禾/急、忙→忄/亡。
- `split-vertical`: 上下拆分，如 愁→秋/心。
- `relation`: 两字靠近、互换、平衡，如 贪/贫、对/错、得/失。
- `metaphor-flow`: 念→种子→因→果、花落、水波、四季流逝。
- `attention-clear`: 名利得失等杂字退场，只留下“我”。
